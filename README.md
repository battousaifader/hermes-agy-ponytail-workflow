# Hermes + AGY + Ponytail Workflow

A private reusable Hermes skill for a planner–executor coding workflow:

- **GPT/Hermes** owns architecture, canonical facts, file-level plans, acceptance criteria, and independent verification.
- **AGY** executes one bounded, explicitly specified implementation slice.
- AGY must stop rather than invent missing product decisions or authoritative domain data.

Install or copy `SKILL.md` into a Hermes skills directory, then load `hermes-agy-ponytail-workflow` for supervised AGY work.
